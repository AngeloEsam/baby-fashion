# Admin Dashboard

This is the standalone administrative interface for the Baby Vision e-commerce site.

## Setup

1.  Install dependencies: `npm install`
2.  Run development server: `npm run dev`
3.  Build for production: `npm run build`

## Features

-   Secure JWT-based login
-   Product management (Create, Edit, Delete, Stock status)
-   Order management (View, Update status, Delete)
-   Premium UI with custom animations and glassmorphism
-   Dark/Light mode support
